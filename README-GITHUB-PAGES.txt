RAÚL BARNICA — GITHUB PAGES

1. Go to https://github.com and sign in.
2. Create a new PUBLIC repository named: raul-barnica
3. Upload index.html and the entire assets folder from this package.
4. In the repository, open Settings > Pages.
5. Under Build and deployment choose Source: Deploy from a branch.
6. Choose branch: main and folder: / (root), then Save.
7. GitHub will provide your public address, normally:
   https://YOUR-GITHUB-USERNAME.github.io/raul-barnica/

IMPORTANT: Keep the assets folder in the same location as index.html.
The site is static and does not require a paid plan or server.
